# 🧮 Математический калькулятор на Go

Консольный калькулятор с математическими операциями, уравнениями и дробями.

## 🚀 Запуск

```bash
git clone https://github.com/krystaltechz/math-calculator.git
cd math-calculator
go run .
```

## ✨ Возможности

- Сложение, вычитание, умножение, деление
- Степени, корни, модуль, факториал
- Тригонометрия (sin, cos, tan)
- Логарифмы (ln, log₁₀)
- Линейные и квадратные уравнения
- Системы уравнений
- Дроби с автоматическим сокращением
- Проценты

## 📁 Структура

```
math-calculator/
├── main.go
└── internal/
    ├── operations/   # математические операции
    ├── equations/    # уравнения
    └── fractions/    # дроби
```
